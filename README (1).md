**To swap one out:** just replace the file with the same name (keep the `.jpg`
extension and the filename). Landscape works best for `01`–`08` (they're
16:10) and portrait for the hero shots.

**To add a whole new chapter:** copy an `<article class="tl-item">` block in
`index.html`, give it the next photo number (`09.jpg`), and drop the file in
here. The site picks it up automatically.

> **Test tip:** open the site in a browser and *click* any photo slot. A file
> picker opens and the picture is remembered on that device — handy for trying
> out a new shot before you commit to files.
